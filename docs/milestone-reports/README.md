# Milestone evidence

Store one report per milestone, named with its MS identifier and phase. Reports record baseline, authorized scope, actual changes, checks with commands/procedures and outcomes, limitations, risks, acceptance checklist, approval reference and next prompt link. Reports provide evidence; [execution state](../governance/09-execution-book.md) remains authoritative for current status.

Acceptance: reports separate facts from assumptions, passing checks from failed/skipped/unrun checks, and review readiness from approved completion. Do not include secrets or client data. See [P0 report](MS-0001-P0.md).
