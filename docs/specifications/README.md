# Specifications

Store approved-phase requirement/design specifications here when detail would obscure the authoritative books. Each specification states owner, phase, version/status, linked REQ/NFR identifiers, acceptance criteria, unresolved assumptions and approval evidence. Link to policy rather than copying it. No detailed specification exists in P0.

[Requirements book](../governance/01-requirements-book.md) owns the requirement catalog; [architecture book](../governance/03-architecture-book.md) owns technical design. Acceptance: traceable scope, explicit proposal/approval status and no conflicting duplicate requirements.
